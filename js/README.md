# JavaScript

Thư mục chứa các file xử lý chức năng của Coffee App.

- main.js: File JavaScript chính.
- customer.js: Xử lý chức năng khách hàng.
- employee.js: Xử lý chức năng nhân viên.
- admin.js: Xử lý chức năng quản trị.
- cart.js: Xử lý giỏ hàng.
- booking.js: Xử lý đặt bàn.
- payment.js: Xử lý thanh toán.
