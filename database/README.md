# Database

Thư mục quản lý cấu trúc dữ liệu của Coffee App.

Các dữ liệu dự kiến:

- users: Thông tin tài khoản khách hàng và nhân viên.
- products: Thông tin đồ uống.
- categories: Danh mục sản phẩm.
- orders: Thông tin đơn hàng.
- tables: Thông tin bàn.
- bookings: Thông tin đặt bàn.
- payments: Thông tin thanh toán.
